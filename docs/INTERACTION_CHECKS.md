# 交互检查

在项目根目录执行：

```powershell
npm run test:unit --prefix cle
npm run test:ui --prefix cle
npm run build --prefix cle
```

自动交互检查使用模拟用户和响应，不会删除真实资料或调用收费模型。只检查本次新增的异常操作：

```powershell
cd cle
node src/tests/run-personal-ui.mjs interactions-ui.mjs
```

## 桌面操作

| 操作 | 应有的结果 |
| --- | --- |
| 点击折线图日期，再把鼠标移出图表 | 日期提示、竖线和底色清除，折线完整可见 |
| Tab 进入日期，按左右方向键、Home / End、Esc | 查看相应日期；Esc 清除提示 |
| 隐藏所有指标、查看空范围或只有一天的数据 | 不显示旧曲线；单日数据仍有可见点 |
| 快速切换时间范围，旧请求后返回 | 保留最后选择的范围，不被旧响应覆盖 |
| 筛选或分页失败，再点击刷新 | 显示错误，不把旧数据当作新结果；重试保留选择 |
| 连点删除笔记、提交注册、发送消息 | 同一次进行中的操作只提交一次 |
| 关闭写信窗口，再打开 | 继续未发送的内容和收件人 |
| 聊天或写信有草稿时离开，选择取消 | 留在当前页面，草稿仍在 |
| 发送中点击取消、Esc、背景或页面跳转 | 等待发送结果，避免隐藏操作状态 |
| 切换群组选择取消，或刷新当前群组 | 保留当前群组和未发送内容 |
| 重选同一附件，或选择超过限制的附件 | 同一文件不重复添加；无效选择不清空已有附件 |
| 网络超时或响应正文停止传输 | 解除等待并提示先确认提交结果，不自动重复提交 |
| 登录或注册提交后离开，响应较晚到达 | 不把用户带回已经离开的页面 |

真实账号的读写范围、账号切换、权限收回和跨用户访问，另按[权限检查](PERMISSION_TESTS.md)验证。上述检查覆盖列出的操作，不替代新功能上线后的相应检查。
