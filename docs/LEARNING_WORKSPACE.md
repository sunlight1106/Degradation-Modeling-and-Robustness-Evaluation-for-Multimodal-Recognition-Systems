# 学习中心使用指南

登录后打开「目录与账户 → 学习中心」。桌面端也可以按 **Ctrl K**（macOS 为 Command K）打开全局搜索。

## 找到资料，再提问

1. 在「资料搜索与问答」输入关键词，选择类型、标签或起始日期后搜索。多个词用空格分隔，例如 `Java 集合` 会查找同时包含这两个词的资料，最多 10 个词。默认优先显示标题相关的结果，也可选择「最近更新」。
2. 点击标题，在页面内阅读原文。支持笔记、知识卡、附件名称、图片识别文字、实验结果与有权限的群组消息。附件内容需先完成图片识别；本版本不会自动解析任意 PDF/Word 附件。
3. 勾选最多 8 份资料，在右侧输入问题，选择已配置的个人 AI。
4. 点击「预览发送内容」，检查所选资料、个人记忆和供应商。确认后才会发起模型调用，费用由供应商计收。
5. 回答中的 S1、S2 对应下方来源列表，点击来源可核对原文。模型生成的引用仍需核对。每份来源最多发送前 2,200 字符，预览显示实际发送范围。

当前检索采用文字匹配，支持中文关键词；它不会声称已经建立向量语义索引。普通个人资料始终限定本人，管理员身份不会扩大个人搜索范围。群组来源要求当前成员拥有内容阅读权限；退出群组、撤销权限、删除或修改来源后，旧问答预览不能继续执行。

## 收藏与常用搜索

1. 搜索结果旁点「收藏」，或打开原文后点「收藏资料」。以后打开「我的收藏」即可继续阅读。收藏保存的是资料入口；原文修改后显示最新内容。
2. 点「已收藏」可移除。已删除或当前无权访问的资料不会显示，点「清理失效收藏」可移除这些入口，包括暂时失去权限的资料。
3. 设置好关键词、类型、标签、日期和排序，点「＋ 保存当前搜索」，填写名称并保存。以后点击名称就会恢复整套筛选条件。
4. 名称旁的 × 删除该搜索。相同条件重复保存会更新名称，不会重复增加一项。
5. Ctrl K 搜索框也会列出前 6 个常用搜索。输入关键词后，用 ↑↓ 选择结果、Enter 打开、Esc 关闭，也可以直接点结果。

收藏和常用搜索随账号保存在数据库中，换浏览器登录同一站点仍可使用。每个账号最多收藏 200 项、保存 50 个搜索；个人数据导出和完整部署备份都包含这些记录。它们不会开放原资料的权限。

## 笔记与资料恢复

- **回收站**：笔记列表或编辑器删除的笔记先进入「学习中心 → 回收站与备份」。点击恢复后回到笔记列表顶层；子页面不随父页面一起删除。恢复不会重新启用旧分享链接。
- **永久删除**：只在回收站内提供，确认后删除正文和历史。回收站不会自动清空。
- **历史版本**：进入笔记编辑器 → 历史版本 → 选择旧版 → 对照两侧正文 → 确认恢复。恢复前的内容仍会成为历史；若笔记已在别处更新，会阻止覆盖。只记录功能上线后的更改，不能找回上线前已经删除的内容。
- **浏览器草稿**：输入会保存在当前浏览器、当前账号的草稿空间。网络恢复并重新打开笔记后，可选择恢复到编辑区或丢弃。保存成功后清除对应草稿；旧版本草稿不会直接覆盖服务器新版。清理浏览器数据会删除这些草稿，公共电脑使用后应清理站点数据。本版本仍不是无需登录和联网即可打开的完整离线应用。

## 从阅读到复习

1. 搜索资料，打开原文 →「制作复习卡」；或在笔记编辑器点击同名按钮。
2. 将原文整理成一个明确的问题和答案，填写学科，保存。复习卡会保留返回来源的入口。
3. 在「复习卡」选择到期复习，先回忆，再显示答案，根据掌握程度评分。
4. 忘记的知识点 10 分钟后再次到期；其他评分逐步延长复习间隔。薄弱知识点可单独筛选，进度随账号保存。
5. 英语笔记中选中一个英文单词 →「选中词加入生词本」，会收藏词库中匹配的词条。词库没有的词可先制作复习卡，或使用已有的私有词书导入功能。
6. 图片识别完成后，在学习中心选择「图片识别文字」，打开结果并点击「存为新笔记」。

## 资料表、看板和月历

打开「资料表」→ 新建资料表 → 修改名称 → 添加资料。默认字段包含学科、掌握程度、下次复习和来源。

「管理字段」可增删文字、日期、数字、选项字段。看板按第一个选项字段分组，在卡片的下拉框切换分组；月历使用第一个日期字段。三种视图共用相同记录。修改后点击保存；其他页面已经修改的内容不会被旧版本覆盖。每张表最多 16 个字段、500 条资料，每页列出 50 张已保存资料表。

## 模型评测

1. 打开「模型评测」，下载 JSON 模板。
2. 每条预测填写样本编号、标准答案、模型名称、版本、输出和状态。耗时/费用不知道时保留 `null`。
3. 同一批样本使用相同的样本编号；同一个编号必须有相同标准答案。一个模型版本对同一样本只能提交一条预测。
4. 填写实验参数和数据来源，导入 JSON 或手动增加预测 →「计算并保存报告」。
5. 查看完全匹配率、字符错误率、失败/缺失数量、已提供的耗时和费用；导出报告会包含原始记录、参数和数据指纹。

这是**批量预测结果评测**，不自动调用多个收费模型。对没有提交的样本计为失败；费用和耗时只汇总已知值，不将未知值当零。字符错误率可能超过 100%，不适用于衡量开放式图片描述的语义质量。演示结果始终标为演示，外部导入结果不会自动获得真实性认证。当前评测不改变已有实验台的演示/真实调用边界。

## 通知和会话搜索

页头「通知」集中显示未读站内信、好友申请和未静音的私聊。在线页面接收实时刷新提示，再通过原有权限接口读取消息。会话、站内信和群组页面自动刷新，连接中断时会重连并保留轮询补偿。

在联系人页面打开一个会话 →「搜索当前会话」，输入关键词查找历史。被清空的本人历史、无权访问和被拉黑的会话不会通过搜索重新出现。通知连接不在地址栏携带登录令牌，不向客户端广播其他用户的消息正文。当前实时连接用于单个后端实例；多副本部署需增加跨实例消息分发。关闭网站后不会发送系统推送。

## 本地训练

设置 → 个人 AI → 本地训练，可选择线性分类器或双层神经网络、随机种子、验证集比例。训练会保留验证损失最低的一轮，显示 Macro-F1 与混淆矩阵；导出的包包含固定的数据划分与指纹，便于复现实验。

模型仍是本机 CPU 运行的小型文本分类器，不是大语言模型。验证集用于挑选模型，不能当作独立测试集。GPT-2 LoRA 学习入口仍在 Colab 执行，不会冒充本平台已经运行的大模型训练。
