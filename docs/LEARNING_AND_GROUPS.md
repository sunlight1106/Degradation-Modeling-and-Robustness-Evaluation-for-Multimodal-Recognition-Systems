# 学习、笔记和群组的新增操作

## 背单词

在「背单词 → 今日学习 → 练习方式」选择：

- **每日带练**：先看场景和搭配，再遮住英文回忆。
- **听音拼写**：点击「听读」，根据声音写单词。答题前隐藏单词、音标与释义；支持美音、英音和慢速。需要浏览器和系统提供英文语音。
- **混合练习**：穿插听写、拼写、搭配和释义识记。
- **分项释义**：将以分号分隔的多义词释义逐项练习，并分别记录错题。
- **易混词**：对照容易混淆的词进行辨析。内置配对仅覆盖常见易混词；当前词书没有合适单词时会提示更换练习方式。

「学习记录」可查看近 7、30、90 天的作答趋势。薄弱项分别显示释义、拼写、听写和具体搭配。一次即时答对、提示后答对与延迟独立回忆仍分开记录，不会因为刚看过答案就算掌握。

同一单词在不同词书中接续已有进度。词书定义不同的释义或搭配分开记录练习情况。词汇备份同时保存新的分项记录；仍可恢复旧版备份，重复恢复不会把次数叠加。

## 笔记

**比较版本**：打开笔记底部「历史版本」，选一个版本。红色表示移除的区段，绿色表示新增的区段；完整旧版与当前正文也可以分别查看。

**处理冲突**：如果另一个页面已经保存了更新，点击「对比并合并」。不重叠的改动会生成合并建议；有重叠时可以查看两份完整正文，编辑合并结果，再点击「应用合并并保存」。保存会再次检查服务器版本，不会跳过冲突保护。标题、分类等字段仍以当前编辑页为准，请一并核对。

**反向链接**：在另一篇自己的笔记中插入当前笔记的链接，例如 `[我的实验](/app/notes/笔记编号/edit)`。目标页「链接到本页」会列出这些笔记。只显示当前账号有权访问的笔记。

**添加图片**：先保存笔记，之后点击「添加图片」，或者直接把图片粘贴到正文输入框。支持不超过 20 MB 的 PNG、JPEG、WEBP，上传会进行内容检查和病毒扫描。正文保留附件标记，右侧预览显示图片。可以从原有的「引用与附件」区域移除引用；移除后图片标记会显示不可用。

图片通过登录后的附件接口加载，不会自动加载正文中的外部图片。分享笔记和导出正文不会自动授予底层图片访问权限；需要图片原件时请另外下载并保管附件。

## 群组

**邀请**：群管理者搜索成员并发送邀请；被邀请人打开「群组 → 邀请与加入申请」，选择接受或拒绝。接受前不进入群组。

**申请加入**：群主在「群组管理」打开「允许通过群组编号申请加入」，将编号告诉对方。申请人在自己的群组页填写编号。管理者在待处理申请中同意或拒绝。

**转让群主**：原群主在「转让与解散」选择现有成员，填写当前密码并确认。新群主获得群组管理权，原群主变为群管理员。

**归档**：群主可归档暂不使用的群组。成员仍可阅读历史，不能发送新消息；恢复后可继续讨论。

**解散**：输入群组全名和当前密码后确认。其他成员立即失去群组访问权，群主保留只读历史。已解散群组不能恢复。

**撤回与举报**：自己的消息可在十分钟内撤回，群组管理者可处理群内消息。撤回后正文与附件入口都失效。举报需要填写原因，只有该群管理者与平台管理员能够查看和处理；其他群组看不到举报记录。

组内阅读、发言、成员管理、设置管理继续按角色和单独配置的权限检查。更改成员身份、移除成员或解散群组后，旧页面和旧附件链接也会重新检查权限。

## AI 接入检查

在「设置 → 个人 AI」保存并启用自己的供应商配置后，可以「查询模型目录」或「测试当前模型」。每次先显示请求内容，再手动确认发送。

连接测试仅发送固定短句，输出上限 128 tokens，不携带笔记、记忆或文件。供应商可能收取费用。文字测试通过不能说明图片或视频接口也可用。模型目录可能分页，首批列表未出现某个模型不代表它一定不可调用。

页面会区分密钥与权限错误、额度不足、限流、模型或端点不匹配、协议不兼容和超时。遇到限流或额度不足，应先查看供应商后台再重试；不要反复发送来确认账单。部署尚未开启远程调用时，检查入口会直接给出启用提示。
